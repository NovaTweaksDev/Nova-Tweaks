# Nova Tweaks

Free and open-source Windows optimization tool focused on performance, privacy,
and simplicity.

Nova Tweaks is an Electron desktop application with a React/Vite interface. It
ships reviewed tweak definitions, PowerShell scripts, and the helper programs
needed for its Windows integrations.

## Download

End users should download the current Windows installer from
[GitHub Releases](https://github.com/NovaTweaksDev/Nova-Tweaks/releases). The
source-code archive generated by GitHub is intended for developers and is not
the installer.

## Local development

Requirements:

- Windows 10 or Windows 11
- Node.js 22 and npm
- Visual Studio Build Tools with C++ and CMake support
- .NET 8 SDK when rebuilding the game detector or monitoring runtime

```powershell
npm ci
npm run dev
```

Useful checks and build commands:

```powershell
npm test
npm run build
npm run dist:local
```

`npm run dist:local` creates an unsigned installer for local testing in
`dist-release/`. Generated `dist`, `dist-release`, helper build, and dependency
directories are intentionally excluded from Git.

## Project structure

- `src/` contains the React interface.
- `electron/` contains the Electron main process, preload bridge, and Windows
  integrations.
- `resources/` contains tweak definitions and reviewed runtime resources.
- `tools/` contains the source for native Nova Tweaks helper programs.
- `scripts/` contains build, packaging, and verification scripts.

The application starts without elevation. Administrator access is requested
only for an explicit operation that requires it. Release builds validate the
integrity of bundled helper programs and third-party components.

## Privacy

Nova Tweaks does not collect telemetry, analytics, or usage data. The
application does not transfer information to other networked systems unless the
user explicitly requests an action such as running the extended network test,
opening the project website, or following an external support link.

The optional extended network test downloads and uploads synthetic test data
to `speed.cloudflare.com` to measure connection performance. Cloudflare receives
the connection's public IP address and request metadata; the upload contains
generated bytes, not personal files. See
[Cloudflare's privacy policy](https://www.cloudflare.com/privacypolicy/).

[Website privacy policy](https://nova-tweaks.com/privacy)

## Code signing policy

Nova Tweaks is preparing an application for free code signing from
[SignPath.io](https://signpath.io/) with a certificate from the
[SignPath Foundation](https://signpath.org/). Approval and signing integration
are pending; current preview installers are unsigned.

- Committers and reviewers: [Elia (NovaTweaksDev)](https://github.com/NovaTweaksDev)
- Approvers: [Elia (NovaTweaksDev)](https://github.com/NovaTweaksDev)
- Privacy policy: [Privacy](#privacy)

The intended signing policy requires approval by an approver for every release
signing request and artifacts built from this repository in GitHub Actions.
The current release workflow uses a separately supplied Authenticode certificate
and is not yet connected to SignPath. Third-party executables retain their
upstream signatures or remain unsigned and are excluded from Nova Tweaks
release signing.
