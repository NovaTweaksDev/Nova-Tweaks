# Support

## Bug reports

Use the [bug report form](https://github.com/NovaTweaksDev/Nova-Tweaks/issues/new?template=bug_report.yml) for reproducible defects. Include the Nova Tweaks version, Windows version, affected feature, and relevant logs after removing private data.

## Feature requests

Use the [feature request form](https://github.com/NovaTweaksDev/Nova-Tweaks/issues/new?template=feature_request.yml) to describe the problem or use case before proposing a large implementation.

## Questions

Search [existing issues](https://github.com/NovaTweaksDev/Nova-Tweaks/issues) first. GitHub Discussions may be used for general questions if it is enabled. Maintainer availability varies, so individual troubleshooting or response times are not guaranteed.

## Security issues

Do not post suspected vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md) for private reporting instructions.

## Downloads

Use [official GitHub Releases](https://github.com/NovaTweaksDev/Nova-Tweaks/releases). The source ZIP and tarball generated by GitHub are not Windows installers. Current preview installers are unsigned and can show an `Unknown publisher` warning.
